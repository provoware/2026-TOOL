# Hilfe – technische Quelle

Die im Tool angezeigte Laienhilfe liegt maschinenlesbar unter `app/static/help.json`. Änderungen an Bedienlogik müssen diese Hilfe mit aktualisieren.

Wichtige Grundsätze:
- keine technische Vorbildung nötig,
- Fehler erklären Was / Auswirkung / nächste sichere Aktion,
- Farbe nie als einzige Information,
- Kernfunktion bei 200 % Zoom erreichbar,
- Sicherheitsprüfungen bleiben in Laie/Profi/Experte identisch.
